# تعميم · Taameem

**من قاعدة جديدة إلى إثبات تنفيذها.**

يصل التعميم الرقابي، يقرأه الذكاء الاصطناعي بالعربية، ويطابقه على سياسات المنشأة
وأنظمتها، ويحوّل كل فجوة إلى مهمة بمسؤول وموعد ودليل مختوم، ثم تقرير جاهز للجهة
الرقابية. سبع خطوات، والقرار للإنسان في كل واحدة منها.

> نسخة عاملة بالكامل. تفتح في المتصفح بلا خادم وبلا قاعدة بيانات.
> `English README: ` [README.en.md](README.en.md)

---

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3100`.

### أوامر أخرى

| الأمر | ماذا يفعل |
| --- | --- |
| `npm run dev` | خادم التطوير على المنفذ 3100 |
| `npm run build` | يبني موقعاً ثابتاً في `out/` |
| `npm run serve` | يشغّل ما بُني، بخادم صغير بلا مكتبات |
| `npm run typecheck` | فحص الأنواع |
| `npm run verify` | فحص اتساق البيانات (انظر الأسفل) |
| `npm run check` | الاثنان معاً، وهو ما يعمل قبل كل نشر |
| `npm run seed` | يولّد ملفات التهيئة في `public/seed-files` |
| `npm run package` | يجمّع مجلد تسليم كامل للعرض |
| `npm run walk` | يمشي الخطوات السبع في متصفح حقيقي ويفشل إن تعطّلت أي واحدة |

لا حاجة إلى تسجيل دخول. تفتح مساحة العمل مباشرة باسم **سارة عبدالله الرشيد**،
رئيس إدارة الالتزام في بنك الابتكار.

## ما استُخدم في البناء

| الطبقة | الأداة | لماذا |
| --- | --- | --- |
| الإطار | **Next.js 15** · App Router | تصدير ثابت كامل، فيعمل من مجلد أو USB أو GitHub Pages |
| الواجهة | **React 19** + **TypeScript 5.7** صارم | الأنواع تمنع أخطاء البيانات قبل أن تصل للشاشة |
| التنسيق | **Tailwind CSS 3.4** مع متغيرات CSS | لوحة ألوان واحدة تخدم الوضعين الفاتح والداكن |
| الأيقونات | **lucide-react** | خفيفة ومتّسقة |
| الخطوط | `next/font` · **Inter** + **IBM Plex Sans Arabic** | تُستضاف ذاتياً وقت البناء، بلا طلب خارجي |
| الحالة | React Context + `localStorage` | لا خادم، والجلسة تنجو من التحديث أثناء العرض |
| قراءة الملفات | File API في المتصفح | تحليل حقيقي للملف الذي يختاره المستخدم |
| ختم الأدلة | **SubtleCrypto** · SHA-256 | البصمة تُحسب من بايتات الملف نفسها |
| التنزيل | Blob API | التقرير وقائمة الأدلة تُبنى في المتصفح |
| أدوات البناء | **esbuild** | تمكّن سكربتات Node من قراءة طبقة البيانات المكتوبة بـ TypeScript |

**صفر اعتماديات وقت التشغيل** خارج React و Next. لا قاعدة بيانات، ولا خدمة خلفية،
ولا استدعاء شبكة من داخل التطبيق.

## المسار: سبع خطوات

الصفحة الأولى هي المسار نفسه. كل خطوة مربع يُفتح على المكان الحقيقي في المنتج،
والمربعات تتلوّن مع تقدّمك، وكل صفحة تنتهي ببطاقة تحملك إلى الخطوة التالية.

| # | الخطوة | من يقوم بها | السؤال الذي تجيب عنه |
| --- | --- | --- | --- |
| 1 | وصول التعميم | تعميم | ماذا صدر، وهل يلزمنا؟ |
| 2 | الذكاء الاصطناعي يقرأه | ذكاء تعميم | ما الذي يتطلبه بالضبط؟ |
| 3 | شخص يعتمده | إدارة الالتزام | هل نقبل هذه القراءة؟ |
| 4 | ما الذي يجب تغييره | ذكاء تعميم | أين نحن اليوم، وأين يجب أن نكون؟ |
| 5 | المهام تصل للإدارات | الإدارات المالكة | من يفعل ماذا، ومتى؟ |
| 6 | جمع الإثبات | الإدارات المالكة | هل نستطيع إثبات أنه نُفّذ؟ |
| 7 | التقرير يخرج | رئيس إدارة الالتزام | ماذا نقول للجهة الرقابية؟ |

التقدّم محسوب مما فعله المستخدم فعلاً، لا من رقم خطوة محفوظ، فالتحديث أو القفز
مباشرة إلى صفحة لا يخرج المسار عن ترتيبه. وإرسال التقرير يُغلق الدورة: يصبح
التعميم مُبلَّغاً عنه، ويُقفل التقرير، وتكتمل الخطوات السبع.

## ما يميّز هذه النسخة

### الرفع حقيقي، لا تمثيل
اختر ملفاً من جهازك فيُقرأ في متصفحك. الأسطر والكلمات ونسبة العربية والأقسام
والأجزاء المرقّمة وعدد ما يحمل واجباً وما يذكر مدة — كلها **مقيسة من ملفك**.
وإن كان الملف PDF أو صورة نقولها صراحة ولا نطبع رقماً لم نقرأه. وبعد الرفع تضغط
على الملف فترى الأجزاء التي استُخرجت منه بنصها العربي والإنجليزي.

### الأدلة مختومة فعلاً
بصمة **SHA-256** تُحسب من محتوى الملف داخل المتصفح لحظة الرفع. أي تعديل لاحق
ينتج بصمة مختلفة.

### التفتيش الذاتي يمشي في المسار
كل ملاحظة يخرج بها التفتيش تتحوّل بضغطة إلى **مهمة حقيقية** على اللوحة: رئيس
الإدارة المالكة بالاسم، وموعد مأخوذ من مدة الإصلاح في الملاحظة نفسها، وست
تعليمات مرقّمة، والدليل المطلوب هو نفسه ما قال المفتش إنه سيطلبه.

### المهام تصل مفهومة
25 مهمة، و149 خطوة مرقّمة، تسمّي النظام الحقيقي ورقم البند والزميل الذي يعتمد،
فلا يحتاج المسؤول أن يتصل بإدارة الالتزام ليسأل ما المقصود.

### الأدوار تغيّر الشاشة
| الدور | ما يستطيعه |
| --- | --- |
| رئيس إدارة الالتزام | صلاحية كاملة، وهو الوحيد الذي يرسل للجهة الرقابية |
| مدير الالتزام | يراجع ويعتمد ويوزّع، ويرفع التقرير **للاعتماد** بدل إرساله |
| أخصائي التزام | يراجع ويجهّز، دون اعتماد نهائي |
| رئيس إدارة | يرى إدارته وحدها: مهامها وأدلتها |
| مراجع داخلي | اطلاع فقط على كامل المنشأة |

لفتح شاشة باسم شخص آخر أثناء العرض، أضف `?as=<رقم الموظف>` لأي رابط، مثل
`?as=E-002`. لا يعرض المنتج هذا في واجهته.

### ثلاث منشآت لا تتقاطع
بنك وشركة تأمين ومؤسسة سوق مالية. لكل واحدة سياساتها وموظفوها وأنظمتها والتعاميم
التي تخص قطاعها وحده. تفتح هذه النسخة مساحة عمل البنك.

| المنشأة | القطاع | سياسات | بنود | موظفون | أنظمة |
| --- | --- | --- | --- | --- | --- |
| بنك الابتكار | بنوك وتمويل | 8 | 134 | 38 | 15 |
| سحاب للتأمين التعاوني | تأمين | 8 | 148 | 23 | 10 |
| روضة كابيتال | سوق مالية | 8 | 138 | 18 | 8 |

### كونسول تعميم
`/admin` — جانبنا نحن: المصادر الرقابية التي نراقبها، وجودة الاستخراج مقاسة بما
فعله موظف الالتزام بكل قاعدة، وحالة العملاء. لا يصل فريقنا إلى سياسات أي عميل ولا
إلى أدلته.

## الجودة

`npm run check` يرفض المرور إذا:

- أشارت بيانات منشأة إلى بيانات منشأة أخرى
- كان لالتزام مالك من إدارة أخرى، أو لمهمة مسؤول من غير إدارتها
- ذكرت شاشة رقماً يخالف المكتبة خلفها
- شُحنت مهمة بلا تعليمات، أو بخطوة فارغة في إحدى اللغتين
- كان اسم موظف عربي غير مكوّن من ثلاثة أجزاء

وهو ما يعمل في `CI` قبل كل نشر.

و`npm run walk` يقود متصفحاً حقيقياً عبر الخطوات السبع من مساحة عمل فارغة:
يفتح التعميم، ويشغّل القراءة، ويعتمد الالتزامات، ويرسل المهام للإدارات، ويُنجزها،
ويرفع دليلاً ويتحقق من ختم بصمته، ويرسل التقرير، ثم يحوّل ملاحظة تفتيش إلى مهمة
ويتأكد من ظهورها في اللوحة. ستة عشر فحصاً، وأي خطوة لا تعمل تُفشل الأمر.
